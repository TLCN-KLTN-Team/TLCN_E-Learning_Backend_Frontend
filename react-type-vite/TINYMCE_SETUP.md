# TinyMCE API Key Configuration

## Để lấy API key miễn phí:

1. Truy cập: https://www.tiny.cloud/auth/signup/
2. Đăng ký với email của bạn (miễn phí)
3. Xác nhận email và đăng nhập
4. Copy API key từ dashboard
5. Paste vào file `.env` hoặc trực tiếp vào `RichTextEditor.tsx`

## Gói miễn phí bao gồm:
- ✅ 1,000 editor loads/tháng
- ✅ Tất cả tính năng cơ bản
- ✅ Không cần thẻ tín dụng
- ✅ Đủ cho dự án học tập/demo

## Sau khi có API key:
Thay thế `'YOUR_TINYMCE_API_KEY'` trong file `RichTextEditor.tsx` bằng API key của bạn.
